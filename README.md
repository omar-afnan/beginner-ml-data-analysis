# 🌸 Iris Dataset: Data Analysis & Visualization

A beginner-friendly data analysis project using Python, Pandas, NumPy, Matplotlib, and Seaborn to explore the famous Iris flower dataset.

## 📌 Project Overview

The goal of this project is to explore the Iris dataset, understand the relationships between flower measurements, and identify patterns across three Iris species.

This project focuses on learning practical data analysis techniques before moving into machine learning.

## 📊 Dataset Information

The Iris dataset contains **150 flower samples** belonging to three species:

- Setosa
- Versicolor
- Virginica

Each sample contains four numerical features:

| Feature | Description |
|---|---|
| `sepal_length` | Length of the sepal |
| `sepal_width` | Width of the sepal |
| `petal_length` | Length of the petal |
| `petal_width` | Width of the petal |
| `species` | Iris flower species |

Each species has 50 samples.

## 🛠️ Tools & Libraries

- **Python**: Main programming language
- **Pandas**: Data manipulation and analysis
- **NumPy**: Numerical operations
- **Matplotlib**: Data visualization
- **Seaborn**: Statistical visualizations

## 🔍 Analysis Performed

The project includes:

1. Loading the dataset using Pandas.
2. Exploring the dataset using `head()`, `info()`, and `describe()`.
3. Checking for missing values.
4. Counting the number of samples for each species.
5. Calculating average measurements for each species.
6. Creating bar charts to compare petal measurements.
7. Creating scatter plots to explore relationships between features.
8. Calculating feature correlations.
9. Visualizing correlations using a heatmap.

## 📈 Key Findings

- The dataset contains 150 samples, with 50 samples per species.
- No missing values were found.
- Setosa has noticeably smaller petal measurements than the other two species.
- Versicolor and Virginica show some overlap in their petal measurements.
- Petal length and petal width have a strong positive correlation of approximately **0.96**.
- Sepal width and petal length have a moderate negative correlation of approximately **-0.43**.
